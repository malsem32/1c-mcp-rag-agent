# Документация для агента (ИТС, стандарты, ваши инструкции)

Сюда кладутся материалы, которые агент должен «знать» сверх кода конфигурации и справки платформы.
Они индексируются в коллекцию справки (`onec_help`) и находятся через `code_help` / `knowledge_search`.

Форматы: `.md`, `.txt`, `.html`/`.htm` (сохранённая страница), `.pdf` (нужен `pip install pypdf`).
Длинные документы режутся по заголовкам автоматически.

Что полезно положить (по убыванию пользы):

1. **Описание вашей конфигурации из ИТС** (по подписке ИТС): «Описание конфигурации», раздел про
   продажи/закупки/склад/взаиморасчёты для вашей редакции (УТ 11 / УПП 1.3 / ERP). Сохраните страницы как HTML.
2. **Стандарты и методики разработки 1С** (its.1c.ru/db/v8std): запросы, блокировки, проведение, формы —
   агенту проще объяснять «почему так плохо» и давать рекомендации.
3. **Ваши регламенты**: какие документы чем оформляются, кто за что отвечает, особенности доработок,
   описание расширений и самописных объектов (`АА_*`, `б_*` …). Это самое ценное — такого нет нигде.
4. Частые ошибки пользователей и их решения (FAQ поддержки).

После добавления файлов:

```
python scripts/index_qdrant.py --help-only
```

Индексация инкрементальная: неизменённые статьи не пересчитываются.

Важно: материалы ИТС распространяются по подписке — индексируйте их только для своей внутренней базы знаний.
