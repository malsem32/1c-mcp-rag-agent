# Примеры фраз менеджера

Передавайте фразу **целиком** в построение отчёта.

## В чат

- продажи по контрагентам за 2015  
- поступления по поставщикам за январь 2015  
- сколько оплат за 2015  
- сравни оплаты январь и февраль 2015  
- счета покупателям за 2015  
- требования накладные какие есть  
- посмотри перемещения  
- список номенклатуры  
- продажи по номенклатуре за 2015
