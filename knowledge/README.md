# Папка знаний

Сюда кладут **простые тексты и списки на русском**.  
Программу трогать не нужно: после правок перезапустите помощника.

## С чего начать

**[шпаргалка_как_работает.md](шпаргалка_как_работает.md)** — что всегда в system prompt, что только через tools, как обновлять, схема целиком.

## Код конфигурации (модули)

Платформа в runtime **не отдаёт** текст модулей.  
Выгрузите: Конфигуратор → «Выгрузить конфигурацию в файлы» → в любую папку; путь к ней задаётся в панели (шаг 1) или `RAG_CODE_DIR=D:\path\to\dump` в `.env`. Выгрузка в репозиторий не входит.

## Справка из hbk

Файлы `.hbk` в папке `info/`. После распаковки:

```
python scripts/unpack_hbk.py
python scripts/clean_platform_help.py
python scripts/drop_stub_cards.py
python scripts/rebuild_help_index.py
```


В `справка_платформы/` — статьи **на русском**, файлы названы по теме  
(не `SUM.md`, а `Агрегатная_функция_СУММА.md`).  
Пустые карточки (только «Имя в платформе» без описания) не храним.  
Поиск: `knowledge_search` («СУММА», «ВЫБРАТЬ», «Массив»…).

## Как добавить своё

1. Новое слово → `словарь_бизнеса.yaml`  
2. Особенность базы → `база/наша_база.md`  
3. Примеры фраз → `заметки/примеры_фраз.md`  

Пишите обычным русским языком.
