1Папка с выгрузкой конфигурации…

В Конфигураторе откройте Конфигурация → Выгрузить конфигурацию в файлы и выгрузите в пустую папку. Затем укажите её путь здесь. Сама база не меняется.

2Хранилище индекса (Qdrant)…

Здесь хранится поисковый индекс по коду. Рекомендуется Qdrant в Docker; без Docker можно работать во встроенном режиме.

3Индексация конфигурации…

Код и метаданные нарезаются на фрагменты и попадают в индекс. Типовая конфигурация на обычном ПК — от 20 минут до нескольких часов; при первом запуске скачивается модель поиска (~1 ГБ). Окно можно закрыть: задача продолжится, ход виден при следующем открытии панели.

      Проверка всей системы
      
      
      Проверяет по порядку: пакеты Python → конфиг → папка выгрузки → пробная нарезка → Qdrant → модель поиска → векторы → поиск по коду → 1С → LLM (нужна только для CLI) → MCP. Первая проверка модели может идти до 10 минут: модель скачивается.
      
      
      
      
      
    
      
    
      Установка и сервисы
      
      
      Первичная установка и обслуживание Qdrant и MCP-сервера.
      
      
      
        
        
        
        
        
      
      
    
      
    
      
    
      
    
      Индексация с ручными параметрами
      
      
      Для опытных: обычно достаточно «Первый запуск», шаг 3, или вкладки «Переиндексация». Папка выгрузки — из настроек. Без галок индексируются только изменённые фрагменты.
      
      
      
        
        
        
        
      
      
      
      
        
        
      
      
    
      
    
      Подбор модели и размера фрагментов
      
      
      Берёт выборку модулей из выгрузки, режет и эмбеддит каждой моделью/размером чанка, меряет качество поиска и скорость, оценивает время полной индексации. Занимает от 10 минут до часа. Модели mpnet (~1 ГБ) и e5 (~2.2 ГБ) при первом запуске скачиваются с Hugging Face.
      
      
      
        
        
        
        
      
      
      
      
        
        
      
      
    
      
    
      Оценка качества поиска
      
      
      Строит вопросы из самой выгрузки (имя процедуры словами, описание, строка из тела, структура объекта, команда формы, параметр макета), прогоняет через боевой поиск и показывает, как часто находится нужное. Занимает 3–5 минут. Результат — во вкладке «Журнал» и в exports/eval_search.json.
      
      
      
        
        
      
      
      
      
    
      
    
      
    
      
    
      Подключить другую конфигурацию
      
      
      Новая выгрузка индексируется в отдельную коллекцию, рабочая не затрагивается: нарезка с чисткой → индексация с проверкой векторов → замер качества на вопросах из этой выгрузки. Галка «сделать рабочей» переключает конфиг после успеха (потом перезапустите MCP). Для быстрой пробы укажите число файлов.
      
      
      
        
        
        
        
      
      
      
      
    
      
    
      Подключение AI-клиента
      
      
      Готовые настройки для Claude Desktop, Cursor, LM Studio и Open WebUI, а также токен доступа — в разделе «Первый запуск», шаг 4.
